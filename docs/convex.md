# Convex (Optional)

This starter template does not include Convex by default.
Add it when you need backend functions or persistent storage.

## Install

```bash
npm i convex
```

## Initialize

```bash
npx convex init
```

## Run locally

```bash
npx convex dev
```

Convex will print a `VITE_CONVEX_URL`. Add it to `.env.local`:

```bash
VITE_CONVEX_URL=...
```

Then restart `npm run dev`.
